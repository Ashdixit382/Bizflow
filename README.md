# BizFlow Manager

AI-inspired SaaS ERP dashboard built with MERN.

## Quick Start
1. `cp server/.env.example server/.env`
2. `cp client/.env.example client/.env`
3. `npm install`
4. `npm run seed`
5. `npm run dev`

## URLs
- Client: http://localhost:5173 (Vite may use 5174 if 5173 is busy)
- Server: http://localhost:5055/api (port 5055 avoids macOS AirPlay using 5000)
